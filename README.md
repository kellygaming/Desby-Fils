# Desby & Fils SARL — site vitrine

Site de **Desby & Fils SARL — Bâtiment & Services** (Cocody Angré, Abidjan) : aménagement foncier, BTP, génie civil, lotissements à Songon et à la Baie des Milliardaires.

## Pages
- `index.html` — accueil : hero, maison qui se démonte au scroll, entreprise, engins sur la route au scroll, services, lotissements, confiance
- `a-propos.html` — histoire, valeurs, projets, galerie
- `contact.html` — WhatsApp, téléphones, e-mail, formulaire (FormSubmit), carte

## Technique
- HTML / CSS / JavaScript sans compilation
- Animations : GSAP + ScrollTrigger, défilement doux Lenis (CDN)
- Scènes au scroll : séquences d'images dans `assets/seq/` (vidéos générées sur fal.ai, découpées avec `.outils/decouper.ps1`)
- Aperçu local : `.outils/serveur.ps1` (http://localhost:8080)
